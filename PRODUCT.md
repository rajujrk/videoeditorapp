# Product

<!-- impeccable:product-schema 1 -->

## Platform

web (the feature guide in `web/`); the product itself is a native macOS app built with Qt Quick.

## Stack

Feature guide: plain static HTML, CSS and JavaScript, no build step and no dependencies. It must
work opened straight from the folder (`file://`, so no `fetch` of local data) and on a static host
such as GitHub Pages under a sub-path (relative links only). No backend.

## Users

TechieVideoEditor (TVE) is a personal project. The feature guide is read by people its author
shares the app with: friends or colleagues trying TVE on their own Mac, who want to know what it
can do, where each feature lives in the app, and the steps to use it.

## Product Purpose

TVE is a desktop video editor for macOS on Apple Silicon: multi-track editing, colour grading,
effects, transitions, titles, audio mixing, on-device analysis and AI, and export. The guide lists
every feature with its title, a description, a screenshot from the app, and how to reach and use
it, so a new user can find and try any feature without reading the source README.

## Positioning

Everything in TVE is original: its effects, transitions, looks, stickers, music, templates and
icons are made for it, and on-device analysis (captions, speech clean-up, people, motion) runs on
the Mac with nothing uploaded. Cloud features are bring-your-own-key only.

## Operating Context

Readers have the app open beside the guide, or are deciding which feature to try. Each feature is
reached from a library tab, an inspector tab, the top bar, the timeline toolbar, a menu or a
keyboard shortcut. The app runs in dark (default) and light themes and in English and Tamil.

## Capabilities and Constraints

- macOS only, personal use, no backend; cloud AI uses the user's own keys (Claude, ElevenLabs,
  OpenAI, Google), kept in the Keychain.
- Feature truth lives in `README.md`; the guide must not claim anything the README does not.
- Guide language: English only.
- Not yet built (must not be presented as available): stem separation; a published pack catalogue
  for the Store (no catalogue or trusted key is published yet).

## Brand Commitments

- Name: TechieVideoEditor, short form TVE.
- The app's design system (`docs/design-system.md`, source `ui/theme/Theme.qml`): neutral
  low-saturation surfaces so the picture comes first, one "Techie blue" accent, dark default with a
  light theme, WCAG AA contrast in both.

## Evidence on Hand

- 99 screenshot pairs (dark and light) generated by the app itself, in `docs/images/` (106 MB as
  PNG).
- Feature descriptions and access paths in `README.md`; the build plan in
  `docs/TechieVideoEditor_Build_Plan.md`.
- No testimonials, users, download page, signed release or pricing exist; none may be invented.

## Product Principles

1. The picture comes first: the guide shows the app's real screens, not illustrations of them.
2. Say where, then how: every feature names the exact place in the app and the steps.
3. Only what is true: nothing beyond what the app does today.
4. Local first: make on-device and bring-your-own-key behaviour clear wherever data could leave the Mac.

## Accessibility & Inclusion

Keyboard reachable, readable in light and dark, WCAG 2.1 AA contrast, matching the app's own bar.
